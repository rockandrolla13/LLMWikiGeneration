# High Frequency Trading with Deep Reinforcement Learning Agents Under a Directional Changes Sampling Framework

## Summary

The paper asks whether deep reinforcement learning (DRL) trading agents can profitably trade high-frequency FX tick data when the underlying data is sampled using directional changes (DC) rather than fixed time intervals, since prior work had combined DC only with shallow, Q-learning/lookup-table reinforcement learning rather than deep networks.

The authors sample nine FX currency pairs at DC thresholds ranging from 0.017% to 0.025% in 0.002% steps, producing 2250 rolling four-week training/validation/test windows. A Proximal Policy Optimisation (PPO) actor-critic agent, restricted to a discrete buy-or-sell action space, is trained on DC-derived indicators (30 input features passed through a lag-5 window into a 150-64-64-2 network) with a reward equal to the realised profit of a closed trade. Hyperparameters, including a filter that only allows trading after a run of consecutive no-overshoot trends, are tuned by grid search on the validation set and then evaluated on held-out test windows against four benchmarks: buy-and-hold (B&H), moving-average crossover (MAC), relative strength index (RSI), and a rule-based low-volatility DC strategy (BLV).

Across a full year of simulated test trading under a 0.025% transaction cost, the DRL agent achieved the best average Friedman rank for both total return and Calmar ratio, statistically outperforming all benchmarks except RSI on return, and outperforming MAC and BLV (though not RSI) on Calmar ratio; on maximum drawdown it ranked essentially level with RSI. Three currency pairs (EUR/CHF, EUR/GBP, EUR/JPY) produced very large total returns at every threshold tested, and DRL's performance on all three metrics improved as the DC threshold increased.

The contribution is combining deep, rather than shallow/tabular, reinforcement learning with DC sampling for high-frequency FX trading, which the authors say had not previously been explored, together with a trade filter that restricts the agent to trading during identified low-volatility, no-overshoot periods.

## Clock and Sampling

**Intrinsic time: one observation per price move of a set size.**

See [[concepts/intrinsic-time|Intrinsic Time]].

Observations are generated by directional-changes (DC) sampling: a trader-set percentage threshold theta marks each significant price reversal in the raw tick series, producing alternating up/down DC events each followed by an overshoot. The RL agent's state is a lag-5 window of the DC-derived indicators (30 input features) plus DC start/end prices, and its holding horizon is simply the interval until it flips its buy/sell position rather than a fixed clock time. Five DC thresholds were tested, from 0.017% to 0.025% in 0.002% increments.

## Data

- **Asset class:** Foreign exchange
- **Instruments:** Nine FX currency pairs: AUD/JPY, EUR/CHF, EUR/GBP, EUR/JPY, AUD/USD, GBP/USD, NZD/USD, USD/CHF, USD/JPY
- **Venue:** TrueFX.com (tick data provider)
- **Period:** 01/05/2022 to 30/04/2023 for AUD/JPY, EUR/CHF, EUR/GBP and EUR/JPY; 01/02/2021 to 31/01/2022 for AUD/USD, GBP/USD, NZD/USD, USD/CHF and USD/JPY
- **Granularity:** Raw tick data, split into rolling four-week windows shifted by one week between windows

## Features and Measures

- **TMV.** The ratio of the whole price move of a DC event to the threshold, computed over a single period.
- **OSV.** The percentage change between the current and previous DC confirmation points, normalised by the threshold; used with 3, 5 and 10-event moving averages.
- **RDC.** The number of ticks in an event adjusted by that event's return, again aggregated with 3, 5 and 10-event moving averages.
- **TDC.** The number of ticks spanned by a single DC event, with 3, 5 and 10-event moving-average variants.
- **NDC.** The cumulative number of ticks spanned over a given number of past DC events (1, 10, 20, 30, 40 or 50 events).
- **CDC.** The cumulative sum of the absolute TMV values over a given number of past DC events.
- **AT.** The difference between the number of ticks spent in up-trends versus down-trends over a given number of past events.

## Method

Data preparation converts raw tick data into weekly blocks, forms rolling four-week windows (shifted one week at a time), and applies DC sampling separately within each window's train/validation/test split. The RL environment (built in OpenAI Gym, trained via the Stable Baselines 3 library with a PyTorch backend) presents a discrete buy/sell decision at each DC-indicator time step and rewards the agent with the realised profit when a position is closed. The PPO actor-critic network uses two 64-unit ReLU hidden layers (overall architecture 150-64-64-2) with a five-step lag on the input window. Hyperparameters are chosen by grid search on the validation set: the required run-length of consecutive no-overshoot trends before trading is allowed is swept over 2, 5, 10 and 20; the state-space lag is swept over 5, 10 and 20; and training length is swept up to 1 million steps, with 200,000 steps found sufficient. Performance on the held-out test year is judged with Total Return, Maximum Drawdown and Calmar Ratio, each derived from per-trade marginal return, and compared across DRL, BLV, B&H, MAC and RSI using a Friedman test with a Conover post-hoc test at the 0.05 significance level.

## Results

- DRL ranked first among all five strategies for total return (average Friedman rank 2.02, test p=1.53e-22) and for Calmar ratio (average rank 1.44, test p=2.53e-36).
- DRL statistically outperformed B&H, MAC and BLV on return, but was not significantly different from RSI (Conover p=2.04e-1).
- On Calmar ratio, DRL statistically outperformed MAC (p=1.16e-46) and BLV (p=9.98e-83), but was not significantly different from RSI (p=4.19e-1).
- On maximum drawdown DRL ranked essentially level with RSI (average rank 2.06 vs 2.03, p=9.50e-1), while BLV showed drawdowns reaching around 80% in some cases.
- EUR/CHF, EUR/GBP and EUR/JPY produced very large total returns at every DC threshold tested, e.g. EUR/JPY reached 11586.09% at the 0.023% threshold.
- DRL's performance on all three metrics improved as the DC threshold increased from 0.017% to 0.025%.
- NZD/USD was consistently the weakest-performing pair across thresholds and metrics.

## Limitations

- Authors note the fixed 0.025% transaction cost used in testing is unrealistic since real spreads can widen when volatility falls, motivating future spread-aware agents.
- Only nine FX pairs were tested, drawn from two different one-year sample periods rather than one consistent window.
- Reader note: the B&H, MAC and RSI benchmarks produce only one value per currency pair (not per threshold), so their values had to be duplicated across the five thresholds to run the Friedman/Conover significance tests, a point the authors themselves flag as a limitation of that testing.
