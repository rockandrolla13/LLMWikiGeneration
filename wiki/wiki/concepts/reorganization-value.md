# Reorganization Value

## Definition

The enterprise value assigned to a debtor in a Chapter 11 plan, usually a capitalized forecast of adjusted EBITDA based on comparable-company multiples. Whitman and Diz note junior classes push for high values so they participate, while high values also load the reorganized firm with more cash-pay debt. They argue low reorganization values favour feasibility. Distressed multiples are set below those of healthy peers.
