# Default-Model-Implied Spread Value Signal

## Definition

A credit value signal defined as the log ratio of the actual credit spread to the spread implied by a default forecasting model. A positive value marks a bond whose spread is wide of its fundamentals. Correia, Richardson and Tuna show that it mean-reverts and predicts one-to-three-month credit returns.
