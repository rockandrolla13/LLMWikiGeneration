# Bankruptcy Recovery Analysis

## Definition

Estimating what each tranche receives by distributing an enterprise valuation down the priority of claims. Claims equal principal (accreted value for discount bonds) plus pre-petition accrued interest. The most senior impaired class is the fulcrum security, which often controls the reorganized equity. The value today is the expected recovery discounted at a target return over the expected length of the case.
