# Absolute Priority Rule

## Definition

The rule that a senior class must be paid in full before a junior class receives or keeps anything. Whitman and Diz locate it in the 'fair and equitable' cramdown test of Section 1129(b) of the US Bankruptcy Code. It binds only when a dissenting impaired class is crammed down, so consensual plans can depart from it. It always governs Chapter 7 liquidation distributions.
